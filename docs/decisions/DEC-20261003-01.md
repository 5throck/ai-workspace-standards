## Ruling

1. **Design Gate**: the fix touches the publisher step that T-20260912-026 and
   T-20260926-015 hardened. It is a logic change, not a typo fix, so E3 does not
   apply and no other exemption category fits. A design doc is required:
   `docs/designs/2026-10-03-edu-sync-publisher-base-reset-design.md` (spec
   `2026-10-03-edu-sync-publisher-base-reset`, new — no existing registry entry).
2. **Core fix**: the publisher resolves the remote default branch from
   `refs/remotes/origin/HEAD`, resets the worktree to that tip, and applies the
   audited bundle on top. The patch bundle is the source of truth; the agent's
   local branch state is expendable.
3. **Same-day rerun hardening**: included now. Force-push the rebuilt branch
   (safe: the tip is a deterministic function of the remote tip and the
   re-validated patches) and skip `gh pr create` when an open PR already
   exists for the branch.
4. **Process note**: specialist dispatch was unavailable this session (the
   platform's subagent backend pins every spawn to a model that does not exist
   on this plan — two dispatch attempts failed with `model-not-found`). The PM
   executed the Row 0 and Row 1 work directly, produced all gate artifacts, and
   logged the deviation in `memory/2026-10-03.md`. User review happens at the
   PR, which carries design, decision record, and fix together.

## ADR assessment

No ADR required. The change repairs a defect inside an existing workflow's
published design boundary; no credential boundary, gate semantics, or schema
changes. Reassess if the publisher ever needs to merge rather than reset, or if
the allowlist gates change semantics.

## Consequences

- `edu-sync` runs no longer depend on the agent leaving HEAD anywhere in
  particular; the 2026-10-02 failure mode cannot recur.
- Same-day re-dispatches converge instead of failing on push/PR creation.
- The trusted step grows by ~6 lines; the credential boundary is unchanged.
