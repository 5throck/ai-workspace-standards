## Decision context

The workspace owner directed on 2026-10-28 that L0-only operational governance
docs must not be verbatim-mirrored into L1 or delivered into scaffolded
projects. Three sweeps verified the inventory (51 L1 doc files, 3 with L0
counterparts in the governance agents dir), the delivery machinery
(propagation domain, GOVERNANCE_L1_FILES instruction-rendition pipeline,
tombstone guard, carry-forward), and the instance state (16/16 byte-identical
copies; co-design already tombstoned on workflows.md). This record fixes the
disposition so the implementing specialists (docs-writer, automation-engineer)
execute against a settled contract; the design doc carries the full file:line
evidence, transform texts, sequencing, and validation plan.

## Conditions attached

1. The root PR lands as one unit: propagation-map excludes, transforms plus
   residual guard, regenerated L1 renditions, L1 file deletion, fork rewrite,
   scaffold-marker narrowing (same commit as the deletion — the parity test
   fails on the stale prefix rule otherwise), and the workspace-schema
   allowlist fix.
2. No per-project deletion before the root PR merges; no `--tombstone` records
   for the retired path (the carry-forward makes the deletion tombstone-free).
3. Hash-verify before every project-side delete: any copy whose content
   diverges from the recorded L1 hash is a STOP-and-escalate, never a delete.
4. `grep -rn "pm-gateway-workflow" templates/` returning zero hits is the
   acceptance gate closing both the transform work and the 16 variant
   pointer-line edits.
