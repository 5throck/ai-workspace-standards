## Decision context

The Test Suite workflow on PR #1875's branch emitted 168 unique warning lines.
The user asked for zero warnings in a separate PR, except the AGENTS.md budget
warnings already ruled WARN-only. The architect reproduced every line locally
on `chore/ci-warning-cleanup` and traced each to its emitting check.

## Ruling

1. **Design approved** — fix source data/prose or the checker for categories
   1–16; keep category 17 (AGENTS.md budget).
2. **False positives fixed in the checker**: comment-line shell-injection
   matches; WS-05 for unregistered co-abap scripts (register as variant-scoped).
3. **Root context.md** warning becomes INFO.
4. **Parallel groups G1–G14** are file-disjoint; serial step S owns shared files.
5. **Rebase on main after #1875 merges**, then re-derive co-consult [o] fixes
   and run S.

## Open items

- ADR-0050 Part 3 heuristic: INFO downgrade recommended, pending user ruling.
- Skill-content merge directions for four skills, pending PM approval.
