## Decision context

DEC-20261106-01 approved consolidating HWP/HWPX authoring into co-work and
removing co-consult's copy. The same day the user changed direction to full
removal. Implementation of the co-work side had started and was fully reverted,
so no co-work artifacts need removal.

## Ruling

Full removal, scoped as listed in `decision` above and in the design's
"Revised decision (2026-11-06)" section. Grep of `templates/common` and
`templates/co-safety` for `hwp-extract|hwpx-generate|extract_hwp|generate_hwpx|hwp-document-processing`
matched only `i18n-layout` (line 92, SSOT + 5 mirrors), which routes HWP
questions to the removed skill; it is added to scope. No file instructs
running the removed scripts.
