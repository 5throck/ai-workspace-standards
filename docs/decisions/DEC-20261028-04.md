## Ruling context

The 2026-10-28 daily review (F-1, Major) found that a set of 2026-10-27 window
commits landed template/code changes without a design doc or spec entry. This
ruling closes the portion of F-1 owned by two commits:

- `154411353` - project-context gate fixes (contract mirror paths, design-lint
  scan-root fallback, readme-sync user-guide seeding, token-compile path and
  provenance) - T-20261027-002, landed as PR #1635.
- `15b7a83d3` - validator hardening wave (pre-commit 6c dead gate rewired,
  DESIGN-R2 theme invariance enforcement, compiler provenance/input precedence,
  language-policy perimeter) - T-20261027-010, landed as PR #1653.

Both are validator-hardening landings whose ticket ids appear only in commit
subjects; `scripts/design-gate-coverage.ts` extracts those ids and reports them
UNCOVERED because no registered spec names them.

## Why retro-backfill and not accepted-legacy

ADR-0074 makes the Design Gate universal: substantive code or template work
carries a spec, regardless of when the work landed. The distinction matters:

- **Accepted-legacy** would assert the work never needed a spec. That is false
  here - both commits introduced gate behavior (C-CM-06, check 6c rewiring,
  theme-invariance enforcement, the language-policy perimeter) that future
  contributors must be able to trace to a design rationale.
- **Retro-backfill** records the rationale after the fact, honestly marked as
  retrospective. The gate's purpose (traceable design rationale) is served;
  the sequencing violation (spec-before-code) is acknowledged rather than
  papered over, and the D8 windowed check is the structural prevention.

## Conditions attached

1. The retro doc describes only what the merged diffs implement - no invented
   post-hoc requirements, no re-scoping of what landed.
2. The registration is `--source manual --status implemented` - the work is
   already merged, so `implemented` reflects reality; the retrospective
   framing lives in the doc header, not the registry status.
3. Scope is the two commits only. Remaining uncovered rows in the window from
   other commits stay open for their own adjudication.
