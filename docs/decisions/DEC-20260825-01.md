## Ruling

A root `.env.sample` drafted in session was rejected by the pre-commit lifecycle gate
(`[FAIL] Stray file in workspace root: .env.sample (not in rootAllowlist)`). The ruling:
do not fight the gate — remove the file. Root scripts consume no required environment
variables (`SYNC_SPEC_EXEMPT` and `CI` are optional flags documented at their call sites),
so a root sample has no content justification either.

## Consequences

- Environment-variable documentation lives ONLY in `templates/common/.env.sample`
  (country-scoped marker blocks per ADR-0058).
- Future root env requirements must first extend `rootAllowlist` WITH spec activity,
  not by dropping files into the root.
