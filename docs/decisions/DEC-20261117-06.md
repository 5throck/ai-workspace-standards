## Context

PM Row 0 (Design Gate) for the sync auto-detection feature. The user approved the
intent with four binding constraints (opt-in only; tickets auto-file but promotion
stays human-judged; auto-merge on green checks or the ADR-0105 billing-block
pattern; close-out merges the project's open PRs). Constraints: design doc + DEC +
spec artifacts only — no implementation edits. Existing machinery that must be
reused rather than duplicated: project-resync Steps 2/2b/2c/2d/2e (manual cycle),
the upstream-request MCP (ADR-0097; design §4/§8/§9/§12; triage §3.12), the
delivered `helpers/local-patch-scan.ts` and `lib/upgrade-policy.ts` leaf modules,
and the 2026-10-07 learning-extraction design. Live precedent: T-20261117-007
(graft→trail echo caught manually today) — pinned as AC-3.
