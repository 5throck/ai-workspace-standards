## Ruling

Owner reviewed the per-skill README standard (ratified 2026-08-28 as part of the
skill-hygiene-and-conventions design) and judged the files unnecessary: SKILL.md is
the machine-consumed definition, the seeded READMEs duplicated its frontmatter, and
the EN/KO pair doubled maintenance for no agent-visible value. Ruling: **retire the
requirement entirely** and remove the files from the template layer.

## Implementation (2026-08-29)

- `scripts/validate-templates.ts` 1.17.0 → 1.18.0: removed `SKILL_README_ENFORCE`
  switch and the per-skill README FAIL/WARN block inside Check B-09.
- CONSTITUTION §6.2 (06-skill-lifecycle.md): standard block replaced with the
  retirement note (only SKILL.md required; hand-written READMEs permitted, ungated).
- Deleted 404 `README.md`/`README_ko.md` files under `templates/*/skills/*/`
  (all variants + templates/common). L0 `skills/*/` copies (where present) left
  untouched as optional dev-home docs.

## Consequences

- `SKILL.md` is again the sole required file in a skill folder across L0/L1/L2/L3.
- The L3 project README backlog authoring cycle tied to this standard is void;
  no project-side gate will flip to FAIL.
- Hand-authored per-skill READMEs remain allowed where genuinely useful, but are
  not seeded, not gated, and not required to be translated.
- The variant-level `README.md`/`README_ko.md` standard (WS-08) is unchanged.
