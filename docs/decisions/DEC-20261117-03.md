consequences: >-
  Fleet syncs stop dying on tracked-but-ignored paths and stop accumulating
  duplicate session blocks; archived memory index rows stop rotting into
  Check 3c WARNs; variant projects scaffolded before their seed gained deps
  get a documented, decision-row-attributed adoption path at the next
  upgrade pass. Costs: one new marker convention in memory logs (verified
  compatible with verify-memory/union-verify structural scans before the
  version bump), force-add visibility line for tracked-but-ignored paths,
  and a small one-time churn as existing same-day duplicate blocks remain
  until hand-cleaned (the fix is forward-looking, not retroactive). Risks
  accepted: R-B1 (force-add restages tracked-but-ignored state — logged),
  R-C2 (deliberate seed-id omission now treated as drift — auditable via

alternatives: >-
  Per design §8 (owner decisions O-4..O-6, defaults applied) and the option
  tables in the design body. O-4 (session-block identity): subject-class
  normalization for the dedup regex (rejected — fragile against every
  derived-subject shape, silently merges distinct runs); no-marker branch
  detection (rejected — blocks carry no branch identity today);
  wipe-and-rewrite of the day's blocks (rejected — destroys other branches'
  conclude-merge entries). Chosen: branch-keyed marker replace. Defect-1
  alternatives: WARN-and-skip for tracked-but-ignored paths (rejected as the
  default — force-add preserves the operator's staged intent and honors the
  sweep contract; skip is retained only for untracked-but-ignored paths);
  template-layer .gitignore negations (rejected — cannot re-include a file
  under an excluded parent directory, verified empirically and documented in
  gitignore rules). O-5 (adoption vehicle): a new `external-deps.ts
  reconcile` CLI subcommand (rejected — bypasses decision-row attribution,
  dry-run framing, and compat-gate placement; the upgrade pass is the
  documented delivery channel). Chosen: pass-only channel 2c. O-6
  (descriptive-row tombstone token): `*(archived — memory/archive, local
  only)*` (rejected as default — longer rows for no gain; the archive
  location is already documented in the index header). Chosen: the index's
  established `*(archived — local only)*` token. Rollout-order alternatives:
  dev-sync PR first (rejected — PR-1 is smaller, stops new dead index rows
  on every subsequent sync, and its landed behavior makes PR-2's landing
  sync safer); a single combined PR (rejected — mixes L1-mirror publishing
  with L0-only engine changes and violates the one-concern-per-PR review
  surface used by the 2026-11-16 batch precedent).
