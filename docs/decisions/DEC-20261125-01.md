## Context

On 2026-11-24 the co-deck delivery stopped on engine-preserved conflicts, the
nightly runner copied template files over nine project-evolved ones, and the
review and upgrade machinery showed the gaps collected in the two designs. The
PM presented a recommendation list on 2026-11-25. The owner answered with one
message.

Evidence. The owner's message, sent 2026-11-25 in reply to the PM's
recommendation list, is `권장대로 진행해줘` ("Proceed as recommended."). It is
the only owner quotation in this record. The recommendations it answered:

1. Merge root pull requests #2172 and #2174.
2. Resolve co-deck in stages, by the classification in
   `docs/reports/2026-11-25-conflict-adjudication-analysis.md`: adopt where
   nothing is lost; port template-side first, then adopt, where something
   would be lost; tombstone `.mcp.json`.
3. Approve both designs on their recommended defaults.
4. Land the machinery batch as one pull request, one commit per row.

## Decision

The approval in the frontmatter is recorded as the ruling.

Scope limits. This decision does NOT approve:

- T-20261124-014 (Actions billing).
- Merging fleet pull requests while private CI is down.
- The co-price high-severity effect advisory waiver.
- The fifteen remaining co-deck files: the white-bubble CSS caps (stage E)
  and the fourteen PNG baselines (stage F). Both go to the owner.

The two designs are marked approved in place. Each open question of the
machinery batch keeps its text and carries a dated ruling line.

PM-level rulings taken under this approval. These are PM rulings, stated as
such. They are not owner decisions.

- Path-limited adopt grants for co-security (one path) and co-architect (six
  paths), each on a content-identity proof: the project copy equals the
  template copy apart from its version line.
- The co-deck adopt grant for 27 paths, and the `.mcp.json` tombstone.
- Merging pull request #2175, whose only protected path is the restoration of
  a memory-file block.

## Consequences

- Root pull requests #2172 and #2174 may merge.
- co-deck proceeds stage by stage. Stages A to D are inside the approved
  course; stages E and F wait for the owner.
- The machinery batch lands as one pull request. Each commit message carries
  its row's canary evidence: the command, its exit code and the key output
  lines. Review is per commit. Every row on a protected path is merged by a
  human.
- The fleet test baseline changes eight template files, as listed in the
  design. The co-deck delivery of 2026-11-25 (co-deck PR #260) already
  reduced the failing tests from 12 to 3.
- Nothing here re-authorizes the nightly runner's suspended billing-wall
  exception or any merge outside the scope above.
