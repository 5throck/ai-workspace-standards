## Context

The canonical architecture map (`docs/architecture/workspace-architecture{,.en,.es,.ja}.svg`,
last changed 2026-11-07, commit `84d080504`) fell behind both handbook clones
on 2026-11-21, when edu-sync branch `edu-sync/2026-11-21b` landed corrected
map content in the handbooks (intro-to-ai-harness PR #87, head `24f833f`;
multi-agent-harness-handbook PR #184, head `9399e44`). The drift direction is
reversed — copies ahead of canonical — and the checker reports
`0 pass, 16 drift, 0 skip`, failing review-baseline battery #10 daily. The
canonical assets carry stale claims (`05:30` cadence vs ADR-0105's unified
03:00 KST, tenants outside the loops, no co-utility chip, frozen additions
note at templates/VERSION 0.28.0) plus the pre-existing `.ja` baseline drift
(Korean root font stack instead of the Meiryo ja stack). Verification found
no hidden consumer of the canonical files and no live document restating the
map's claims (§3–§4 of the design), so a single byte-copy adoption closes the
whole gap.

## Decision

As recorded in the frontmatter: Row 0 = NOT exempt (design doc required);
ruling = adopt the handbook post-edit assets as canonical via the gated
byte-copy in `docs/designs/2026-11-21-canonical-archmap-refresh-design.md`
§2, landed per its §7 rollout. Status is `proposed` pending user ratification
of the design summary; it becomes `accepted` when the adoption PR merges with
the checker at 16/0.

## Consequences

As recorded in the frontmatter. Governing surfaces: the four canonical SVG
files only — no script, page, template, CI job, or record is modified.
