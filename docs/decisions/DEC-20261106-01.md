## Decision context

The user directed on 2026-11-06 that HWP/HWPX authoring consolidate into
co-work and that co-consult's HWPX tooling be cleaned up. The design carried
three open questions (§6) plus a runtime choice (D2). Two record problems
motivated it: co-consult ships Python despite ADR-0036/ADR-0087, and the
2026-10-09 injector-promotion design claimed that promotion had resolved to
deprecation while T-20261005-026 shows it was promoted.

## Ruling

1. **Design approved.**
2. **Q1 → (c)**: co-work sole owner; co-consult files removed directly
   (user-requested cleanup justifies skipping the deprecation cycle).
3. **Q2 → co-work-local** scripts + Bun tests; no L0 change.
4. **Q3 → out of scope.**
5. **D2 → option A (TypeScript)**; fflate reused, cfb added, node:zlib for
   BodyText, fast-xml-parser if needed.
6. **D5 erratum** added to the 2026-10-09 design (single dated line).

## Evidence

- ADR-0036 / ADR-0087: runtime standard and its exception list.
- T-20261005-026: result "both scripts stay active" — contradicts the
  2026-10-09 design text.
- Design §1 inventory of co-consult HWP assets.
