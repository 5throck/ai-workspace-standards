## Decision context

Four defect groups in the delivery bookkeeping layer were verified across
the engine (upgrade-project.ts), the shared policy/helper libs, the two
lifecycle audits, dev-sync's CHANGELOG gate, and the nightly fleet guard:
stale frontmatter dates that every upgrade wave re-flags (~29 warnings
fleet-wide, co-abap 21/21 agents; co-safety 8 + 21), a tombstone clear
catch-22 whose core fix already shipped but is untested and unauditable,
a one-shot retirement script that cannot pass delivered hooks and whose
purpose is served, and two small polish items (silent stub version
divergence; a wrong census comment). This record fixes the disposition so
the implementing specialists execute against a settled contract; the
design doc carries the file:line evidence, the primitive contracts, the
five-PR sequencing, and the validation plan. Status `accepted` records the
gate-moment adoption; implementation starts only after the user approves
the design at the approval gate — nothing is registered by this dispatch.

## Conditions attached

1. The change/review date split is binding on every future delivery path:
   engines may advance `last_updated` (top-level and nested
   `lifecycle.last_updated`) and must never write `last_reviewed`.
2. The A2 tolerance may only key on baseline-hash equality from the
   delivery manifest — never on commit-subject patterns or date windows.
3. PR1 lands the re-stamp extension, TOMBSTONE_CLEARED row, prune
   symmetry, and --changelog-entry as one engine unit with its unit
   tests (step-4.85 gate applies); PR2's audit tolerance depends on
   nothing else landing first but reviews against PR1's baseline
   semantics.
4. The live 01:30 cron prompt gains the `-m --diff-filter=D` invocation
   at the next runner session; until then the SSOT doc is the record and
   the resync-audit TOMBSTONE-VIOLATION row is the deterministic backstop.
5. No per-project CHANGELOG write occurs without --changelog-entry; the
   flag's first fleet use is the next daily resync wave, announced in
   that wave's PR body.
