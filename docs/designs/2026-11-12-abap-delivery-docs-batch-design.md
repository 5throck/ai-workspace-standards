## U-20261112-010 — graft-era doc blocks survive delivery; parity check L0-only

**Defect** (from the ticket): the graft→trail fleet standard (870cd776f, 2026-11-08) rewrote `templates/common/{AGENTS,CLAUDE,GEMINI,HERMES,CODEX}.md` and every variant AGENTS.md, but missed the 15 variant `HERMES.md` copies and `templates/co-architect/CODEX.md`. The tool-owned `<!-- graft:start -->…<!-- graft:end -->` block sits outside every COMMON-*/WORKSPACE-MANAGED zone, so (a) the MERGE pass preserves the delivered project's graft-era prose forever, and (b) TB-01 (`trail-block-parity.ts`) covers only AGENTS.md, so the drift was invisible.

**Ruling — smallest sound mechanism (three pieces, one contract)**:

1. **Template sources (L1/L2)**: all 15 variant `HERMES.md` graft blocks and `templates/co-architect/CODEX.md` swapped byte-identically for the corresponding trail block from `templates/common/HERMES.md` / `CODEX.md` (mechanical, marker-anchored).
2. **Detector arm (L0)**: `checkTrailBlockParity` in `scripts/validate-templates.ts` (TB-01) extended with (1) HERMES.md/CODEX.md trail parity (common seed == variant copy where the variant carries the file) and (2) graft-era block detection — any `<!-- graft:start -->` block in an instruction file (AGENTS/CLAUDE/GEMINI/CODEX/HERMES) across `templates/common` + every variant is an **Error**. Era-marker based, not prose based.
3. **Delivered-side detector (upgrade-project v1.104.0)**: after the MERGE and DOCS_MERGE passes touch an instruction file, `swapGraftForTrail` (lib/trail-block-parity.ts v1.1.0) replaces a delivered graft block with the template's trail block (`TOOL_ERA_SWAP` ADOPT decision row). Refused when the template side itself still carries a graft block (a not-yet-migrated template can never push a swap); idempotent; dry-run reports only. Delivered projects converge at their next upgrade visit — no `Projects/` hand edits.

**Files**: `scripts/lib/trail-block-parity.ts` (1.0.0→1.1.0), `scripts/validate-templates.ts` (TB-01 arm), `scripts/upgrade-project.ts` (1.103.0→1.104.0), `scripts/SCRIPTS.md` (both rows), 16 template docs, `tests/unit/validate-trail-block-parity.test.ts` (+8 tests, incl. two real-template sweeps).
