- **Spec ID**: 2026-10-25-fleet-anchor-repair
- **Date**: 2026-10-25

- **Tickets**: CI evidence co-abap PR #218 run 39945617179 (Documentation Audit FAIL, 2 broken anchors)

## Summary

Three delivered markdown links point at GitHub anchors (`#5-agent-dispatch-rules`,
`#6-native-sub-agents-agent-tool`) that exist only in L0/L1 platform docs. 11 of 16
project `CLAUDE.md` files (co-abap, co-architect, co-consult, co-deck, co-develop,
co-export, co-game, co-newbiz, co-price, co-safety, co-security) dropped the numbered
`### 5.` / `### 6.` scaffolding headings during past merges, so the delivered copies of
`docs/governance/agents/pm-gateway-workflow.md` and `execution-plan-templates.md` fail the
project Documentation Audit. The heading `## Execution Plan Boilerplate` (anchor
`#execution-plan-boilerplate`, per `headingSlug` in `scripts/validate-docs-links.ts` —
lowercase, non-alphanumerics dropped, spaces → hyphens) is verified present in **every**
relevant file: root `CLAUDE.md:254` / `GEMINI.md:223`, `templates/common/CLAUDE.md:254` /
`GEMINI.md:223`, and all 16 project `CLAUDE.md` + `GEMINI.md` files on main. The decision:
re-point all three links at `#execution-plan-boilerplate` and fix the wording so no "§5/§6"
heading is claimed.

## Delivery path

Lands at L0 via the dev-sync PR. Fleet propagation is by tooling only — the nightly
01:30 KST runner (`auto-release-template.ts` → patch release → `project-resync`
upgrade wave) delivers the fixed L1 docs into all 16 projects. **No project repo is
edited directly** (ADR-0031). New scaffolds inherit the fix immediately.

## Alternatives rejected

- **Patch the 11 project repos directly** — violates ADR-0031 (no direct project edits); drifts on next resync.
- **Re-add `### 5.`/`### 6.` headings to L2 CLAUDE.md** — resurrects a merge-prone scaffolding heading and requires fleet-wide CLAUDE.md surgery; the anchors were already dropped by past upgrades, so restoring them fights the delivery channel.
- **Inline the alias table into the Note** — duplicates registry-checked content outside the managed surfaces list (`sync-model-registry.ts` SURFACES would miss it on the next model bump).

## Risks / rollback

- **Missed variant mirror** → PM-04 parity fails at step 3 (Error severity) before any commit; fix is the same one-line edit. No silent drift path exists.
- **Wording regression in the Note** → `validate-model-registry.ts` only checks the tier-list lines, so it would NOT catch Note edits; the unit test asserts key structure only. Mitigation: exact before/after strings above; review diff for single-line scope.
- **Rollback**: single `/sync` PR — `git revert` restores L0; re-run step 2 to regenerate mirrors; no project-side artifact to clean (projects receive the fix only via resync).
