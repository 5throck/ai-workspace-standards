## Focus-Area Answers (TL;DR)

1. **New-project deployment of agents/skills**: The delivery mechanism is genuinely strong (declarative SSOT `scripts/helpers/scaffold-markers.ts`, contract two-way validation, CI tripwires, rollback discipline) — **but three defect classes break it in both directions**: (a) L0/workspace-only skills **leak into** every scaffold (`swe-solve`, `simulate-pipeline`, and 8 `l2_propagate: false` skills via `.agents/skills`), (b) the upgrade path **silently withholds** contract-declared common skills (`i18n-audit`, `handbook-sync-audit`, `handbook`), and (c) the scaffolded `AGENTS.md` references three skills that do not exist at L1.
2. **Locale ("country") setting vs general path**: Two different axes are conflated in the question — and the workspace treats them differently. The **jurisdiction axis (`--country`) is end-to-end healthy** (validated → registry-driven prune of 5 bases → ACTIVE.md/context/template-version recording → upgrade re-delivery with same pruning). The **language/locale (i18n) axis is validator-only**: no creation-script plumbing exists, L3 Phase A drafts never receive `docs/workspace-schema.json` (language validator degrades to ko-only), and the only per-variant locale exemption key (`country_config.locales`) is documented nowhere — dead code. Nothing breaks mechanically today in either path, but the locale-configured path exists only as hand-authored convention.
3. **Upgrade**: documented `--platform both` hard-errors (renamed `all` in v1.34.0); version citations stale in two docs (v1.28.0 / v1.22.0 vs actual 1.39.0); a version-bumped core-script fork passes as `OK`; contract common-skills withheld; `.codex/skills` leak re-delivered.
4. **Variant-ization**: `--domain ehs` (skill's own example) silently types the scaffold `collaboration`; stale citation to nonexistent `docs/country-profiles.md`; k-* country-scoped lists show 3 of 6 registry skills.
5. **Template promotion**: promotion materializes only `.claude`/`.gemini`/`skills/` mirrors (`.agents`/`.codex` start empty); country-scope matcher misses `.codex/skills`; scan categories blind to `.codex`/`.agents`; variant-level mirror freshness unchecked (co-safety: `.claude` 60 vs `.agents` 8 skills).

**Security verdict (Slot D)**: clean — no secrets/personal paths in templates/skills/scripts; gitleaks + pre-commit hook delivery verified with drift auto-fix; CI least-privilege (`contents: read`, SHA-pinned); language policy scan 1,849 files, 0 violations.
