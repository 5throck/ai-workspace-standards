## Description
Staged retrofit playbook for adopting a design token architecture in an
existing (brownfield) UI built from raw hex/px/rgba literals. Carries the
domain-neutral distillation of the co-price method: Stage 0 foundation (token
SSOT with 3-layer architecture + Tailwind v4 `@theme inline` bridge + honest
`scanRoots`/`tokenSources` lint config, no UI change), per-layer codemod stages
(type scale → color with near-duplicate collapse only under a computed WCAG
contrast proof → radii/shadows/layout), one PR per stage with an explicit
allowlist delta and ADR-0070 visual evidence, and the machine-verified
allowlist-residue sweep (remove-entry-then-relint; co-price went 158 → 131
entries). Process guidance only — no code, no template promotion.

Position in the token skill family: `token-usage-lint` is the detection half,
`design-foundation` is the greenfield prerequisite (Stage 4), this skill is the
retrofit workflow. Operator-level skill (workspace root); `l2_propagate: false`
— L1/fleet propagation is deferred until a second variant demands the retrofit
or the upstream lint substrate stabilizes at P2+.
