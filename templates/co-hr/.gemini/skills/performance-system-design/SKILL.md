## Context

Use in Phase 2 whenever an engagement requires designing or redesigning a performance management system. Owned by the Performance Management Consultant. Any linkage to actual pay outcomes is drafted here but finalized in coordination with `compensation-benchmarking` — this skill does not set pay outcomes unilaterally.

## When to Use

- When selecting or redesigning an evaluation framework
- When designing how organizational goals cascade to team/individual level
- When designing a rating scale and calibration process
- When designing feedback cadence and 1-on-1 structure
- When a merit-linkage (rating → increase %) matrix needs to be drafted for compensation review

## Execution Steps

1. **Evaluation Framework Selection**:
   - Assess org maturity and culture (e.g., early-stage vs. established, autonomy-driven vs. process-driven) to match a framework: KPI-based, OKR, competency-based, or a hybrid
   - Document the rationale linking the chosen framework to the maturity/culture assessment — do not default to one framework without justification

2. **Cascade Design**:
   - Define how org-level goals decompose to team-level and then individual-level goals/KPIs/OKRs
   - Preserve line-of-sight: every individual-level goal must be traceable back to a team or org-level goal — flag any orphaned individual goal that doesn't cascade from a higher-level objective
   - Specify the cascade timing (e.g., annual org goals set first, then team, then individual, on what cadence)

3. **Rating Scale and Calibration Process Design**:
   - Define the rating scale (number of points, anchor definitions per point)
   - Design a cross-manager calibration process explicitly aimed at controlling rating inflation and bias (e.g., forced distribution guardrails only if justified, calibration meeting structure, evidence requirements per rating)
   - Flag any calibration design that relies solely on a single manager's judgment without cross-check

4. **Feedback Cadence Design**:
   - Define cadence: annual, semi-annual, or continuous
   - Define 1-on-1 structure (frequency, standard agenda elements) supporting the chosen cadence
   - State how the cadence choice supports the framework selected in Step 1 (e.g., continuous feedback pairs naturally with OKR check-ins)

5. **Compensation-Linkage Design**:
   - Draft a merit matrix mapping rating level → suggested increase % range
   - Explicitly label this as a draft for review by the Compensation & Benefits Analyst — coordinate rather than setting the final pay outcome unilaterally
   - Note any funding/budget constraint assumptions used in the draft matrix

## Output Format

- **Performance System Design Doc**: Framework Selected + Rationale, Cadence, Calibration Process
- **KPI/OKR Cascade Template**: Org Goal, Team Goal, Individual Goal, Line-of-Sight Check
- **Merit-Linkage Matrix (Draft)**: Rating Level, Suggested Increase % Range, Budget Assumption, Review Status (pending Compensation & Benefits Analyst)
