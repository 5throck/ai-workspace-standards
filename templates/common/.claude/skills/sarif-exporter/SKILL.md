# 📊 Skill: sarif-exporter

## Context

Interoperability between security scanning tools, threat matrix modeling, and modern security management platforms (such as GitHub Code Scanning, DefectDojo, and CI/CD reporting dashboards) requires a standardized reporting format.

`sarif-exporter` defines rules, specifications, and execution patterns for serializing vulnerability findings, static analysis results, secret detection alerts, and DREAD threat matrix outputs into valid OASIS **SARIF v2.1.0** (Static Analysis Results Interchange Format) JSON files.

## When to Use

- Serializing security scan outputs (`security-scan`, static analysis, secret detection) into standardized JSON reports.
- Exporting threat findings and DREAD risk matrices generated by `stride-threat-matrix` for dashboard ingestion.
- Integrating security audit artifacts into CI/CD pipelines (e.g. GitHub Actions Code Scanning uploads).
- Converting custom security rule violations into OASIS-compliant SARIF structures.

## Execution Steps

1. **Finding Collection & Normalization**
   - Extract findings from scanners, audit scripts, or threat matrices.
   - Normalize finding properties: rule ID, rule name, full description, severity rating, file location, start line, start column, and remediation guidance.

2. **Severity Mapping to SARIF Levels**
   Map internal or DREAD severity levels to standard SARIF `level` properties:
   - **Critical / High (DREAD $\ge 6.0$)**: SARIF `level: "error"`
   - **Medium (DREAD 4.0 - 5.9)**: SARIF `level: "warning"`
   - **Low (DREAD $< 4.0$)**: SARIF `level: "note"`
   - **Informational / Pass**: SARIF `level: "none"`

3. **SARIF v2.1.0 Object Construction**
   Construct the root JSON object following schema `$schema: "https://raw.githubusercontent.com/oasis-tcs/sarif-spec/master/Schemata/sarif-schema-2.1.0.json"`:
   - `$schema`: URI pointing to official SARIF 2.1.0 JSON schema.
   - `version`: `"2.1.0"`
   - `runs`: Array containing tool execution metadata (`tool.driver.name`, `tool.driver.version`, `tool.driver.rules`) and `results` list.

4. **Location Reference Formatting**
   - Format target file paths as relative URIs using forward slashes (`file.path` or `scripts/audit.ts`).
   - Specify `physicalLocation.artifactLocation.uri` and `physicalLocation.region` (`startLine`, `startColumn`, `endLine`, `endColumn`).

5. **Report Serialization & Validation**
   - Serialize formatted JSON structure to destination path (e.g. `reports/security-scan.sarif`).
   - Validate JSON syntax and required SARIF schema fields before completing export.

## Output Format

```json
{
  "$schema": "https://raw.githubusercontent.com/oasis-tcs/sarif-spec/master/Schemata/sarif-schema-2.1.0.json",
  "version": "2.1.0",
  "runs": [
    {
      "tool": {
        "driver": {
          "name": "ai-workspace-co-security-exporter",
          "version": "1.0.0",
          "rules": [
            {
              "id": "SEC-STRIDE-001",
              "name": "ElevationOfPrivilege",
              "shortDescription": {
                "text": "Unauthenticated CLI invocation vulnerability"
              },
              "fullDescription": {
                "text": "The command processor accepts unauthenticated calls over internal IPC sockets without signature verification."
              },
              "help": {
                "text": "Enforce verify-authorization gate before executing CLI command dispatches."
              },
              "properties": {
                "security-severity": "8.2"
              }
            }
          ]
        }
      },
      "results": [
        {
          "ruleId": "SEC-STRIDE-001",
          "level": "error",
          "message": {
            "text": "Elevation of privilege vulnerability detected in Command Processor with DREAD score 8.2."
          },
          "locations": [
            {
              "physicalLocation": {
                "artifactLocation": {
                  "uri": "scripts/dispatch.ts"
                },
                "region": {
                  "startLine": 45,
                  "startColumn": 1
                }
              }
            }
          ]
        }
      ]
    }
  ]
}
```
