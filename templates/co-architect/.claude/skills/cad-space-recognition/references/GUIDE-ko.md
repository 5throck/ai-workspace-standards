# CAD 공간 인식 — 한국어 사용자 안내

> 이 문서는 [`../SKILL.md`](../SKILL.md)의 한국어 안내서입니다. 절차는 SKILL.md와 같습니다. 여기서는 **한국어로 말하는 사용자와 소통하는 방법**을 정리합니다: 알림 문구, 검토 표 양식, 용어.
> 규칙: 사용자에게는 한국어로 답합니다. 파일 안의 키, 코드, 커밋·PR 문구는 영어로 씁니다.

## 1. 한눈에 보는 흐름

| 단계 | 하는 일 | 사용자에게 보여 줄 것 |
|------|---------|----------------------|
| A. 근거·이미지 | 도면을 열고 선·호·문자를 뽑은 뒤, 원본에서 평면 이미지를 직접 그림 | "원본에서 선 N개, 문자 N개를 뽑았습니다" |
| B. 제안 | 판독 규칙(R01–R12)을 적용해 실 경계를 제안하고, 벽·통심선에 붙임 | 겹친 그림과 실 목록(면적 포함) |
| C. 창·문 | 문 호와 창 선을 찾아 실 경계에 배정 | 문·창 표. 확인이 필요한 항목은 따로 모아 제시 |
| D. 검토 | 사용자 보정을 하나씩 반영하고 그림을 다시 그림 | 바뀐 내용(좌표·면적)과 남은 질문 |
| E. 채점·저장 | 정답 데이터와 제안을 비교해 점수를 매기고, 파일과 규칙에 기록 | 통과 수, IoU, 점수가 치우쳤는지 여부 |

## 2. 알림 문구 예시

- **시작**: "도면을 열었습니다. 벽·창·문 층을 확인한 뒤 평면 이미지를 원본에서 직접 그리겠습니다."
- **제안 후**: "실 N개를 제안했습니다. 실 이름이 모두 자기 실 안에 들어가는 것을 확인했습니다. 겹친 그림을 보시고 틀린 곳을 알려주세요."
- **보정 반영**: "〈실〉의 〈경계〉를 원본 벽(x 12,345)에 맞춰 옮겼습니다. 면적은 9.4㎡ → 13.8㎡가 됐습니다."
- **되돌리기**: "말씀대로 〈항목〉을 원래대로 되돌렸습니다. 나중에 다시 넓히지 않도록 메모에 적어 두었습니다."
- **점수가 치우친 경우**: "이 점수는 제 제안을 고쳐서 만든 정답과 비교한 것이라 실제보다 좋게 나옵니다."
- **점수가 내려간 경우**: "버그를 고쳤더니 점수가 5/9 → 4/9로 내려갔습니다. 앞의 값은 버그 덕분에 나온 것이었습니다."

## 4. 반드시 물어볼 것 (자동으로 정하지 않음)

1. 실내 벽 위의 창 층 이중선이 문인지, 아니면 문이 아닌지 (R06)
2. 출입문 근거가 없는 실의 출입구 위치 (R07)
3. 선으로 둘러싸였지만 이름이 없는 칸을 어떤 공간으로 볼지, 비워 둘지 (R09)
4. 발코니를 확장형으로 볼지 (R02). 벽이 없으면 실에 합치는 것이 기본값
5. 대칭 세대가 있으면 대칭 기준선이 맞는지 (R10)
6. 두 벽 사이의 좁은 띠(약 400mm 이하)가 공간인지. 기본값은 "공간 아님"(벽 사이 빈 곳)으로 비워 두고, 방 경계는 자기 벽 중심선에서 끝냅니다. (R25)
7. 한 공간 안에 있는 문(샤워부스 문 등)이나, 반대편 공간이 아직 없는 문이 정말 문인지. 확인되면 `internal` 또는 `unmodelled_side`로 표시합니다. (R26)
8. 도면 기준값(ground truth)이 없는 도면에서 기하 방식이 찾은 공간을 쓸지. 이 공간은 "검토 전 후보"(`candidate`)로만 보여 주고, 사용자가 확인하기 전에는 확정값으로 쓰지 않습니다. (ADR-019 C안)

## 5. 용어

아래 표는 검토 절차 용어입니다. 한국어 건축용어 전체(공간·문·창·면적·규제 용어와
온톨로지 개념 대응)는 [`GLOSSARY-ko.md`](GLOSSARY-ko.md)를 참고합니다.
활성 국가는 `CAD_COUNTRY`(기본 `KR`)로 정해집니다.

| 한국어 | 영어 (파일·코드) | 설명 |
|--------|------------------|------|
| 실 | room | 채점 대상 공간 |
| 비실 영역 | non-room zone | 발코니, 화단, WET ZONE, 배관 공간(PD/AD), 코어 |
| 공용 코어 | shared core | 엘리베이터, 계단, 홀. 대칭 복제하지 않음 |
| 통심(선) | grid centerline | 정답 데이터의 실 경계 기준 |
| 벽 안쪽 면 | wall inner face | WET ZONE처럼 벽을 넘으면 안 되는 영역의 경계 |
| 확장형 | expanded balcony | 벽 없이 실에 합쳐진 발코니 |
| 문 호 / 경첩 / 문짝 | door arc / hinge / leaf | 호의 중심 = 경첩, 반지름 = 문짝 폭 |
| 문설주 | jamb | 문 호 없이 문설주만 있는 문도 있음 |
| 창 선 | glazing run | 평행한 창 층 선 2개 이상 |
| 대칭 세대 | mirrored unit | ID 끝에 `R`, 이름 끝에 `_R` |
| 정답 데이터 | ground truth | `memory/drawings/<도면>.ground-truth.json` |
| 판독 규칙 | reading rules | `docs/reports/room-scoring/reading-rules.json` |
| 겹친 그림 | overlay | 원본 선 위에 제안이나 정답을 겹쳐 그린 SVG |

## 6. 한국어 표기 주의

- 실 이름은 원본 그대로 저장합니다(`욕   실`처럼 공백이 들어간 것도 그대로). 공백은 비교할 때만 정리합니다.
- 치수는 천 단위 쉼표를 찍은 mm(`2,300`), 면적은 소수 첫째 자리 ㎡(`13.8㎡`)로 씁니다.
- 좌표를 말할 때는 통심선 이름(X4, Y5)이나 원본 좌표(x 16,129)를 함께 적어, 사용자가 도면에서 바로 찾을 수 있게 합니다.
