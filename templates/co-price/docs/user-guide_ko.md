# co-price 사용자 가이드

> **대상**: 플랫폼을 사용하는 기획자, 재무 전략가, 컨설턴트
> 영문 버전: [`user-guide.md`](user-guide.md)

## 1. 계정 발급

1. `http://localhost:9981` 접속 후 **회원가입** 클릭
2. 이름·이메일·비밀번호 입력 후 제출
3. 신규 계정은 관리자 승인까지 **대기(pending)** 상태로 유지됩니다.
4. 승인 후 **로그인** 페이지에서 로그인합니다.

> 관리자는 `/admin`에서 계정을 관리합니다(승인·정지·비밀번호 강제 변경).
> 최초 관리자는 임시 비밀번호로 로그인하면 필수 변경 절차로 안내됩니다.

## 2. 핵심 개념

| 개념 | 의미 |
|---|---|
| **회사(Company)** | 최상위 조직. 프로젝트를 소유합니다. |
| **프로젝트(Project)** | 하나의 시뮬레이션 모델: 제품·채널·원가·재무 시드. |
| **채널(Channel)** | 판매 경로(D2C, 백화점, 오픈마켓 등) — 공급률과 믹스 비율 보유. |
| **공급가** | 해당 채널에서 제조사가 단위당 수령하는 금액 (MSRP × 공급률). |
| **BEP** | 손익분기점 — 누적 영업이익이 양전환되는 시점. |
| **VDT** | 가치 동인 트리(Value Driver Tree) — 이익 드라이버 분해. |

## 3. 시뮬레이션 구성

1. **프로젝트**를 생성하거나 선택합니다.
2. 대시보드에서 좌→우로 탭을 구성합니다:
   - **Sales** — 제품 라이프사이클 연도, 채널 정책, 배분(믹스 합계 100%),
     가격 전략, 포트폴리오 매트릭스.
   - **Costs** — 인건비(CEO/리더/멤버 스케일링 규칙), 생산 원가(BOM 기반),
     판관비(SG&A 산식).
   - **재무 시드** — 자본금과 기초 잔액.
3. 결과는 최대 **60개월**까지 자동 재계산되어 세 개 재무제표 탭에
   표시됩니다: **손익계산서 · 재무상태표 · 현금흐름**(워터폴 차트 포함).

모든 통화 계산은 고정밀 산술을 사용하며, 수량은 정수,
백분율은 0~100%를 입력합니다(성장률·물가 상승률은 100% 초과 허용).

## 4. 분석 도구

- **BEP 분석 탭** — 연도별 손익분기 도달 시점.
- **가치 동인 트리** — 연도별 매출/원가 드라이버 상세 분석.
- **인텔리전스 매트릭스** — 제품 × 채널 × 연도 가격 포지셔닝 그리드(3종 뷰).

## 5. 다국어 및 통화

- **설정**에서 언어/통화 변경 (RTL 아랍어 포함 16개 로케일).
- 환율은 매주 월요일 자동 동기화됩니다(오프라인 수동 수정 가능).

## 6. 내보내기

**Export** 클릭 시 현재 시나리오의 Excel 워크북이 생성됩니다
(재무제표·가정·월별 상세). 표준 납품용 한국 사업계획서 서식
(제조/유통 v2.5)도 제공됩니다.

## 7. 문제 해결

| 증상 | 조치 |
|---|---|
| 가입 후 "pending"에서 진행 없음 | 관리자에게 계정 승인 요청. |
| 믹스 비율 검증 오류 | 채널 믹스 비율 합계가 100%여야 합니다. |
| 차트가 비어 있음 | 활성화된 채널에 수량 목표를 설정했는지 확인. |
