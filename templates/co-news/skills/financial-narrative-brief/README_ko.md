## 목적

Guides financial-analyst through converting raw k-dart DART data into an article-ready narrative brief. Explicitly distinct from co-consult's financial-statement-analysis (which builds a 5-level ROIC/valuation driver tree) — this skill is narrative-oriented, not valuation-oriented, and produces structured data for a reporter, not a full financial model. Use when: Phase 1, immediately after an assignment names a target company.

- **스코프(scope)**: `co-news`
- **버전**: 1.0.1
