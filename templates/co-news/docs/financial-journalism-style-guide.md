# 한국 경제/금융 저널리즘 스타일 가이드

> 본 가이드는 한국 경제 일간지 및 IB 전문지의 실제 기사에서 추출한 스타일 규칙을 정리한 것으로,
> `financial-journalism-style` 스킬과 `style-editor` / `reporter` 에이전트의 실행 참조 문서입니다.

---

## 1. 개요

### 1.1 목적

co-journalist 파이프라인에서 생성되는 기사가 실제 한국 경제/금융 저널리즘의 문체를 자연스럽게 따르도록
구체적인 규칙과 패턴을 제공합니다. 기존 `financial-journalism-style` 스킬의 고수준 지침을 보완하는
상세 참조 자료입니다.

### 1.2 레지스터 정의

| 레지스터 | 특징 | 적용 기준 |
|---------|------|----------|
| **경제 일간지** (기본) | 접근성 높은 일반 경제 톤, 금융 지식이 있는 일반 독자 대상 | 기본값. Phase 0에서 별도 지정이 없는 경우 적용 |
| **IB 전문지** (보조) | 조밀한 IB/PE 전문 용어, 자본시장从业者 대상 | Phase 0에서 명시적으로 지정된 경우에만 적용 |

## 2. 경제 일간지 스타일 (기본 레지스터)

### 2.1 문체와 등록 (Register)

**해라체 (평어체, -다/-한다 종결)**

- 모든 기사 본문은 해라체로 작성합니다. 해요체(~해요)나 하십시오체(~습니다)는 사용하지 않습니다.
- 1인칭 대명사(나, 저)와 주관적 감정 표현은 배제합니다.
- 중립적, 사실적, 권위적인 톤을 유지합니다.

**모달 표현 (불확실성의 교율적 전달)**

금융 기사에서는 단언보다 calibrated uncertainty(교율된 불확실성)를 사용합니다.

| 표현 | 뉘앙스 | 사용 상황 |
|------|--------|----------|
| ~전망이다 | 전망/예상 | 분석가 예상, 시장 컨센서스 |
| ~것으로 분석된다 | 분석적 판단 | 리서치 보고서 기반 분석 |
| ~것으로 보인다 | 추정 | 정확한 확인이 어려운 상황 |
| ~수 있다 | 가능성 | 미래 시나리오 |
| ~받았다 | 사실 전달 | 확정된 사실 |

**금지**: "~입니다", "~요", "~라는 점에서 주목할 만하다" (과도한 강조), "~기 때문이다" (원인 단언 — "~에 기인한다" 또는 "~때문인 것으로 분석된다"로 대체).

### 2.2 헤드라인 규칙

**구조 공식**

헤드라인은 항상 구체적 수치나 핵심 사실을 포함한 명사구 형태입니다.

**공식 A (거래/이벤트 중심)**:
```
[기업] + [핵심 수치/규모] + [행동/이벤트] + [맥락/조건]
```

**공식 B (분석/전망 중심)**:
```
[기업] + [지표] + [추세/전망] + [원인/동인]
```

**예시**:
- `OO기업, OOO억원 규모 OO 인수… 시장점유율 O위`
- `OO, O분기 영업이익 O% 성장… 수익성 개선 기대`

**핵심 규칙**

| 규칙 | 설명 |
|------|------|
| 수치 필수 | 헤드라인에 반드시 구체적 수치 포함 (금액, %, 순위 등) |
| 명사구 | 주격 조사(-은/는), 서술어 종결 사용 금지 |
| 줄임표 활용 | 두 번째 절을 줄임표(...)로 자르는 후킹(hooking) |
| 질문형 금지 | "OO기업, 인수할까?" 형태 불가 |
| 괄호 태그 미사용 | `[단독]`, `[속보]` 등 기사 유형 태그 사용하지 않음 |
| 기업명 선두 | 헤드라인 시작은 항상 기업명 또는 주체 |

### 2.3 리드 문단

리드(첫 문단)는 기사의 핵심을 2~4문장으로 전달합니다.

**구조**:
1. **핵심 사실/수치** — 가장 중요한 정보를 첫 문장에
2. **5W1H** — 기자, 장소, 대상, 원인, 방법을 첫 2문장 이내에 배치
3. **최우선 수치** — 기사에서 가장 중요한 숫자를 반드시 리드에 포함

**예시**:
```
OO기업이 OOO억원 규모의 OO 사업을 추진한다. OO일 확인된 이번 사업은
전년 동기 대비 O% 증가한 규모로, 해당 분야에서 O번째로 큰 거래다.
```

**수정된 역피라미드 구조**: 단순 역피라미드에 분석적 심화(analysis layer)를 더한 형태.
리드 → 상세 데이터 → 시장 맥락 → 출처 인용 → 시사점 → 전망.

### 2.4 문단 구조

**기본 원칙**: 1문단 = 1논리단위 = 2~4문장

**문단 기능별 패턴**:

| 순서 | 기능 | 내용 |
|------|------|------|
| 1 | 리드 | 핵심 사실 + 최우선 수치 (2~4문장) |
| 2 | 상세 | 지표 상세, 추가 수치 |
| 3 | 시장 맥락 | 동종 업계 동향, 거시적 배경 |
| 4 | 출처 인용 | 기관 분석가 또는 업계 관계자 발언 |
| 5 | 시사점 | 해당 사건의 의미와 영향 |
| 6 | 전망 | 향후 일정, 규제 전망, 타임라인 |

**문장 길이**: 중간~긴 문장이 지배적. 복문(종속절 포함 문장)이 일반적이지만,
한 문장이 3절을 넘지 않도록 합니다.

### 2.5 금융/비즈니스 데이터 표현

**숫자 표기 규약**

| 항목 | 규칙 | 예시 |
|------|------|------|
| 대규모 금액 | 한국 단위(조/억/원) 사용 | `1조2000억원` (O `1200억원` 또는 `1.2조원`) |
| 백분율 | 아라비아숫자 + % 기호 | `15%`, `32.4%` |
| 비교 기간 명시 | 반드시 기준 기간 포함 | `전년 동기 대비`, `전분기 대비`, `전일 대비` |

**비교 구조 공식**:

```
OO기업의 O분기 영업이익은 전년 동기 대비 O% 증가했다.
OO의 O분기 매출은 전분기 대비 O% 높다.
O월 기준 수준은 OOO원 수준으로, ~에 달했다.
```

**범위 표현**:
```
~O억에서 O억 사이
~O%에서 O%대
```

**기록 표현**:
```
~를 기록했다 (비교 기록)
~에 달했다 (최고치/최저치 도달)
```

### 2.6 인용구와 출처 표기

**패턴 A — 간접 인용 (가장 빈번)**:
```
업계 관계자는 "OO할 것으로 전망된다"고 말했다.
```

**패턴 B — 기관/연구원 귀속**:
```
OO증권의 OO연구원은 "~~~"라고 분석했다.
```

**패턴 C — 공시/공식 발표 기반**:
```
OO일 공시에 따르면, ~~~
OO기업은 ~~~라고 밝혔다.
```

**규칙 요약**:

| 규칙 | 설명 |
|------|------|
| 간접 인용 우선 | 직접 인용보다 간접 인용("라고 분석했다/말했다") 선호 |
| 기관 귀속 우선 | 개인 연구원명보다 기관명(OO증권은)을 먼저 표기 |
| 인용부호 | 한국어 인용부호 (" ") 사용 |
| 다중 출처 | 출처 간 대조가 아닌, 단일 서사에 대한 순차적 지지로 배치 |
| 귀속 동사 목록 | `분석했다`, `말했다`, `밝혔다`, `전망했다`, `평가했다` |

### 2.7 전환어와 논리 연결어

**최소 사용 원칙**: 한국 경제 저널리즘은 명시적 전환어를 최소로 사용합니다.
논리적 흐름은 문단의 주제문(topic sentence)이 담당합니다. 기사당 1~2개만 사용합니다.

**핵심 연결어 목록**:

| 연결어 | 기능 | 사용 빈도 |
|--------|------|----------|
| 이에 / 이에 따라 | 인과 (따라서) | 높음 |
| 반면 | 대조 | 보통 |
| 다만 | 예외/한계 (그러나) | 높음 |
| 특히 | 강조 | 보통 |
| 한편 | 화제 전환 (그런데) | 보통 |
| 앞서 / 이어 / 이어서 | 시간 순서 | 보통 |
| 또한 / 아울러 | 추가 정보 | 낮음 |
| ~때문에 / ~로 인해 | 인과 원인 | 보통 |
| ~에 기인한다 | 인과 귀속 | 낮음 |
| ~면서도 | 동시/대조 | 낮음 |

**금지 패턴**:
- "첫째, 둘째, 셋째" 등 기계적 열거
- "한편으로는 ~반면으로는" 같은 과도한 병렬
- 매 문단 시작에 같은 전환어 반복

### 2.8 전문 용어 처리

**직접 사용, 인라인 정의 없음**: 독자는 기본 금융 지식을 갖추고 있다고 가정합니다.

| 용어 유형 | 처리 방식 | 예시 |
|----------|----------|------|
| 한국어 금융 용어 | 그대로 사용, 정의 없음 | 유상증자, 감자, 영업이익, 주식매수청구권 |
| 영어 금융 용어 | 외래어로 그대로 사용 | M&A, IPO, PBR, ROE, MBO, SPAC, ESG, VC, PE |
| 맥락이 필요한 경우 | 정의 대신 프레이밍으로 설명 | `PBR O.5배 수준으로 저평가` (PBR이 뭔지가 아니라 저평가라는 점을 강조) |

**규칙**:
- 영어 약어/용어는 한국어 문장 내에 그대로 삽입합니다.
- 대문자 약어(IPO, M&A 등)는 대문자 그대로 유지합니다.
- 용어 설명을 위한 괄호 삽입은 하지 않습니다.
- 유사어 변환(예: "엑시트" → "투자 회수")은 하지 않고 업계 용어 그대로 사용합니다.

## 3. IB 전문지 스타일 (보조 레지스터)

Phase 0에서 명시적으로 지정된 경우에만 적용합니다. 기본 레지스터(경제 일간지)와의 주요 차이점:

### 3.1 경제 일간지와의 차이점

| 차이점 | 경제 일간지 | IB 전문지 |
|--------|----------|----------|
| 용어 밀도 | 기본 금융 용어 | IB/PE 전문 용어 고빈도 (LBO, GP/LP, IRR, CoC) |
| 설명 수준 | 일반 독자 이해 가정 | 업계从业者 이해 가정, 용어 축약 없음 |
| 시장 표현 | 풀네임 사용 | 시장 압축 표현 (예: "버팀목 전망" 등 시장 관용구) |
| 섹션 태그 | 미사용 | 기사 유형별 섹션 태그 사용 |
| 문장 구조 | 비교적 긴 설명형 | 조밀한 정보 압축형 |

### 3.2 섹션 태그 분류

IB 전문지에서는 기사 유형을 나타내는 섹션 태그를 사용합니다:

- `[Market Watch]` — 시장 동향 분석
- `[IB 풍향계]` — IB 산업 트렌드
- `[지배구조 분석]` — 기업 지배구조 변화
- `[IR Briefing]` — 기업 IR/실적 발표 분석
- `[desk]` — 데스크 칼럼/오피니언
- `[i-point]` — 투자 포인트 요약

### 3.3 마무리 문장 규칙

IB 전문지 특유의 소프트 클로징(soft closing) 패턴:

```
~하는 모습이다.    (관찰적 마무리)
~할 것으로 예상된다. (전망적 마무리)
```

## 4. 공통 규칙 (두 레지스터 공통)

### 4.1 숫자 표기

| 항목 | 규칙 |
|------|------|
| 금액 | 한국 단위 사용: 원, 만원, 억원, 조원 |
| 백분율 | 아라비아숫자 + %: `15%`, `3.2%` |
| 배율 | 아라비아숫자 + 배: `1.5배`, `0.8배` |
| 단위 생략 | 문맥이 명확한 경우 금액 단위 축약 가능 (예: "O000억으로 ~") |

### 4.2 날짜 표기

| 항목 | 형식 | 예시 |
|------|------|------|
| 과거 날짜 | `O월 O일` | `8월 10일` |
| 미래 날짜 | `오는 O일` | `오는 15일` |
| 상대 날짜 | `오늘`, `어제`, `내일` | `어제 발표된` |
| 연도 비교 | `전년 동기`, `전년` | `전년 동기 대비` |
| 분기 | `O분기` | `3분기 영업이익` |

### 4.3 기업명 표기

- 법인 정식 명칭 또는 업계 표준 약칭을 사용합니다.
- 임의적 애칭이나 비공식 명칭은 사용하지 않습니다.
- 외국 기업의 경우 첫 등장 시 한국어 표기(있는 경우) + 영문명:

```
OO(영문명)는 ~
```

### 4.4 영문 용어 처리

- 업계에서 널리 쓰이는 영문 약어/용어는 한국어 문장에 직접 삽입합니다.
- 외래어 표기법에 따른 한글 표기가 있는 경우, 해당 표기도 허용합니다
  (예: M&A = 엠앤에이, 하지만 원문 그대로 사용하는 것이 일반적).
- 대문자 약어는 대문자 그대로 유지합니다.
- 첫 등장 시 약어 풀네임을 괄호로 설명하지 않습니다.

## 5. AI 생성 텍스트에서 피해야 할 패턴

본 섹션은 `ai-tell-reduction` 스킬과 연동됩니다.
style-editor는 아래 패턴을 특별히 주의하여 스캔합니다.

### 5.1 한국어 AI-tell 패턴

| 심각도 | 패턴 | 예시 | 수정 방향 |
|--------|------|------|----------|
| 의미 왜곡 | 번역투 (beonyeoktu) | "~임을 알 수 있다", "~는 것으로 보아진다" | 직접 서술: "~다", "~했다" |
| 산만함 | 기계적 열거 | "첫째, ~. 둘째, ~. 셋째, ~" | 자연스러운 흐름으로 재구성 |
| 산만함 | AI 특유 관용구 | "주목할 만하다", "흥미롭게도" | 삭제 또는 구체적 분석으로 대체 |
| 산만함 | 과도한 헤징 | "일반적으로 ~일 수 있다고 여겨진다" | 근거를 명시하거나 단언 |
| 미관 | 수동태 과다 | "~에 의해 ~되었다" | 능동태로 전환 |
| 미관 | 불릿/이모지 과다 | 기사 본문에 ●, 🔥 등 사용 | 산문으로 변환 |
| 미관 | 균일한 문장 길이 | 모든 문장이 비슷한 길이 | 길이에 변화를 줌 |
| 의미 왜곡 | 과도한 접속사 | "또한", "게다가", "더불어"를 매 문단에 | 최소 사용 원칙 적용 |

### 5.2 하드 제약: 수치/인물 보존

스타일 편집 중 다음은 100% 원본 그대로 유지합니다 (ai-tell-reduction 스킬의 zero figure drift 규칙):

- 고유명사 (기업명, 인물명)
- 숫자, 금액, 비율
- 날짜
- 직접 인용문 (따옴표 내)

수치 포함 문장은 편집 후 반드시 fact-checker의 인용 원장(ledger)과 diff 비교합니다.
