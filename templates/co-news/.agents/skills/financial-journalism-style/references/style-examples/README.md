# Style Examples

Drop real sample articles from target outlets here (e.g. Sedaily at sedaily.com, TheBell at thebell.co.kr) to calibrate the `financial-journalism-style` skill against actual house style rather than general knowledge.

One file per sample article. Plain text or Markdown is fine. Include the source URL and publication date at the top of each file.

This folder is empty by design in the Phase A prototype — populating it with >=3 real samples and re-calibrating the skill is a required condition before Phase B promotion (see `PROMOTION_CHECKLIST.md`).
